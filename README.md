# Purple Love Site 💜

Open `index.html` in your browser to view it.

## How to customize
- **script.js** (top, CONFIG block): title, subtitle, letter, captions/dates, song path, final message.
- **assets/photos/**: your photos as photo-01.jpg ... photo-06.jpg
- **assets/music/**: your song as our-song.mp3
- **style.css**: purple colors are CSS variables at the top (:root).
- **index.html**: page structure and section titles.

No photos/music yet? Use the "Add your photos" and "Choose song" buttons on the page (temporary until refresh).
